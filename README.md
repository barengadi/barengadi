# Bareng Adi - Kelas Privat Visit Home AI & Automasi Bisnis (Medan)

Website landing page statis bertema **Clean & Minimalist (White Theme)** dibangun dengan **Next.js (App Router, Static Export)**, **Tailwind CSS**, dan **TypeScript**.

- **Lokasi:** Area Kota Medan dan sekitarnya (Deli Serdang, Binjai, dll.).
- **Harga:** **Rp 249.000 / sesi pertemuan** (durasi jam fleksibel via WhatsApp).
- **100% Statis Tanpa Backend:** Terintegrasi langsung ke WhatsApp untuk pemesanan jadwal.

---

## 🛠️ Menjalankan & Membangun

### Preview Lokal
```bash
npm run dev
```
Buka browser di [http://localhost:3000](http://localhost:3000).

### Build Statis (Production)
```bash
npm run build
```
File statis otomatis masuk ke folder `out/`.
